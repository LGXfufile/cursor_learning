# 审课时

按下面清单看，只报真实问题：

1. 侧栏文案、`contentMap.title`、页面 `h3` 是否一致。
2. 步骤是否写了具体点击位置（Customize、Marketplace、命令面板），有没有只写口号。
3. 代码块能否直接复制；模板尖括号是否已转义。
4. 外链是否指向现行 Cursor 文档（`https://cursor.com/docs/...`），不要用过期的 `cursor.sh` 路径充数。
5. 示例插件路径是否和仓库真实文件对得上。
